# BetappaBharath Banking API TestLab

## 🚀 Live Application

[Open Banking API TestLab](https://betappabharath-api-testlab.bharathbetappa.workers.dev/)

## 📚 Project Overview

A hands-on banking API testing platform designed to practice and demonstrate
real-world API testing concepts.

## 🔐 Authentication

- Bearer token authentication
- Token expiry validation
- Isolated user sessions

## 👥 Customer & Account APIs

- Customer CRUD
- Multi-account support
- Account validation

## 💳 Transaction APIs

- Transaction creation
- Transaction validation
- Positive and negative scenarios

## 🧪 API Testing

- Swagger / OpenAPI
- Postman collection
- Response assertions
- Status-code validation
- Negative testing
- REST Assured examples

## 🛠️ Technology

TypeScript | REST APIs | Postman | OpenAPI/Swagger | REST Assured |
Playwright | Cloudflare Workers | D1
